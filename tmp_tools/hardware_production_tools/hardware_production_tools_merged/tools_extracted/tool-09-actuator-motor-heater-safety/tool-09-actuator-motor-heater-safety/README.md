# Tool 09 — Actuator / Motor / Heater Safety Interlock

Offline HTML production tool for planning safety interlocks across the 14 research ZIP projects.

Open `tool-09-actuator-motor-heater-safety.html` in any browser.

Includes:
- Tool purpose and use boundary
- 14-project applicability map
- Production-stage map
- Checklist and pass/fail gates
- Risk table
- Example safety-chain and firmware state-machine pattern
- JSON/export-ready receipt schema for LogicHub/GN8R use

Safety boundary:
This is a planning/checklist artifact, not a safety-rated controller. Physical emergency stops, fuses, relays/contactors, guards, isolation, certification, and qualified review are mandatory where applicable.

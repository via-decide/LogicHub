Thermal / Current / Power Derating

Use when a device can overheat, brown out, overload, melt an enclosure, reset under peak load, mislabel its current rating, or fail in field ambient conditions.

Power integrity + heat boundary

Purpose

This tool converts every power and heat assumption into a release gate. It requires each project to close its rail budget, input-envelope, fuse/wire/connector current path, thermal path, brownout behavior, enclosure heat-soak, and derated operating claim before production.

rail budget current path fuse / breaker dropout heat soak brownout derating receipt
Do not skip

A device that works on a bench supply can still fail in a real enclosure, long cable, hot room, battery sag, startup spike, sealed plastic case, moving robot, heater chamber, EVSE relay box, or outdoor station.

This tool is a planning and evidence artifact, not a certification, simulation replacement, or permission to energize mains, batteries, motors, heaters, or high-voltage systems.

Core derating model

Electrical

Input source, fuse, reverse protection, TVS, regulator, rail loads, inrush, cable drop, connector current, PCB trace current, brownout threshold.

Thermal

Regulator dissipation, MOSFET/driver heat, heater duty cycle, motor driver temperature, enclosure airflow, chamber heat, ambient range.

Product claim

The label must rate the assembled path, not a single component. Claim only the current, ambient, runtime, and duty cycle proven by evidence.

Quick equations

Linear regulator heat

P_diss = (V_in - V_out) × I_load
T_junction ≈ T_ambient + (P_diss × θJA)
Rule: pass only if T_junction stays below derated limit.

Cable voltage drop

V_drop = I_load × R_cable_total
V_load = V_source - V_drop
Rule: pass only if V_load remains above regulator dropout + brownout margin.

Battery runtime

runtime_hours ≈ usable_capacity_Ah / average_current_A
Use derating: usable_capacity = rated_capacity × 0.6 to 0.8
Rule: publish realistic runtime, not ideal runtime.

Complete current path

rating = min(source, fuse, wire, connector, PCB trace, switch, relay, driver, load, enclosure thermal limit)
Rule: weakest link defines product rating.

Pass checklist

Pass / fail gates

PASS

Measured values prove the device survives worst-case load, high ambient, startup, sag, cable drop, enclosure heat-soak, and declared duty cycle with safe temperature and voltage margins.

FAIL

Any rail browns out, any connector/wire/regulator overheats, any fuse value is guessed, any battery/runtime claim is ideal-only, or any live mains/motor/heater path lacks qualified safety review.

Example power derating pattern

INPUT→ FUSE / BREAKER→ REVERSE / TVS→ POWER PATH→ REGULATORS→ LOADS→ TEMP + CURRENT TELEMETRY→ SAFE STATE 
// Minimal firmware-side derating state machine
state POWER_BOOT:
  sample vin, rail_5v, rail_3v3, board_temp
  if rail_invalid: enter FAULT_POWER_RAIL
  if temp_high: enter FAULT_THERMAL
  enter POWER_READY

state POWER_READY:
  allow low-energy UI and diagnostics
  block motor/heater/charger/high-load until calibration and derating gates pass

state LOAD_ACTIVE:
  every 100 ms:
    sample current, voltage, temperature
    if voltage_sag or over_current: disable load; enter FAULT_POWER_LOAD
    if temp_warning: reduce duty cycle / current limit
    if temp_critical: disable load; enter FAULT_THERMAL

state FAULT_*:
  output safe state
  retain fault code
  show local message
  require explicit reset after cause is removed

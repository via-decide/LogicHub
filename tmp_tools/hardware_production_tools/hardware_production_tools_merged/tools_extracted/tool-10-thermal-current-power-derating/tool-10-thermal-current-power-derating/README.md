# Tool 10 — Thermal / Current / Power Derating

Standalone HTML tool for the universal hardware production stack.

## Purpose
Use this when a device can overheat, brown out, overload, melt an enclosure, reset under peak load, or make an unsafe current/runtime claim.

## Contains
- Purpose and safety boundary
- 14-project applicability cards
- Production-stage map
- Pass checklist
- Pass/fail gates
- Risk table
- Example firmware-side derating state machine
- LogicHub/GN8R JSON export schema

Use when

Use this tool whenever a human, fixture, cartridge, cable, toolhead, battery, sensor, camera, board, sample, or robot must physically mate with another part.

Rule: a safe interface should make the correct action obvious and the wrong action mechanically difficult or impossible.
  • A cartridge must only fit one way.
  • A connector must not be reversible unless it is electrically safe in both orientations.
  • A toolhead, sample holder, battery, or module must guide itself into alignment before pins touch.
  • A fixture must locate the unit before test probes apply force.
  • A guard or cover must expose enough service access without exposing moving blades, belts, hotends, high voltage, or pinch zones.

Design checklist

  • Every connector, module, cartridge, dock, and service part has one defined datum.
  • Wrong orientation is blocked before electrical pins, optics, blades, belts, or hot parts are reached.
  • Contact pins engage only after mechanical lead-in has aligned the part.
  • There is a clear insertion stop: seated depth must not depend on user judgment.
  • Retention is deliberate: latch, screw, detent, magnet, clip, or bracket is documented.
  • Release path is visible and does not require prying against fragile PCB, lens, cable, or printed wall.
  • Connector labels are still readable after assembly.
  • Service access works with realistic fingers/tools and does not expose a hazard zone.
  • Material process is accounted for: 3D print shrink, injection-mould draft, metal bend radius, sheet tolerance.
  • Critical interfaces have pass/fail dimensions and can be checked by a fixture.

Pass / fail gates

PASS: a first-time user can complete the correct insertion/connection/service action without guessing orientation, using force, or reading a long manual.
FAIL: any physically possible wrong insertion can short power, bend pins, break optics, expose a moving/hot/high-voltage hazard, or miscalibrate a system silently.
GatePass conditionFail condition
Wrong orientation blockPart cannot reach electrical/mechanical engagement when reversed.Reversed insertion reaches pins, blades, belt path, optics, or latch.
Insertion forceSeats smoothly within defined force range.User must wiggle, hammer, pry, or force the part.
Datum repeatabilityPart lands in same location across repeated cycles and units.Alignment depends on human skill or flexible cable position.
Retention and releasePart stays secure in operation and releases by intended action.Falls out under vibration or requires destructive removal.
Service safetyTool/finger access is available without opening hazard zones.Service action exposes mains, hot barrel, blades, belts, props, or moving wheels.
Manufacturing inspectionCritical dimensions can be measured or checked with go/no-go gauge.Supplier cannot verify fit before final assembly.

Example cartridge slot pattern

8MB CARTRIDGE SLOT GEOMETRY
- datum_A: left rail inner wall
- datum_B: rear seating stop
- key_feature: right-side offset rib
- lead_in: 1.0–1.5 mm chamfer on slot mouth
- pin_protection: housing reaches guide depth before pogo/header contact
- retention: detent or captive screw
- label: TOP / INSERT direction molded or engraved

Wrong insertion tests:
1. upside-down blocked before pins touch
2. reversed blocked before pins touch
3. partial insertion cannot report READY
4. forced insertion leaves visible mechanical interference before electrical damage

Example fixture logic

fixture_check:
  locate_unit:
    - confirm datum_A seated
    - confirm datum_B seated
    - confirm latch_closed == true
  then_apply_power: true
  then_probe:
    - continuity
    - flash_id
    - i2c_device_scan
    - led/display state
  block_if:
    - latch_open
    - wrong_variant_key
    - insertion_depth_out_of_range
    - probe_force_over_limit

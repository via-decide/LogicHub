Tool 13

Enclosure / Environmental DFM

A production tool for turning exposed prototypes into safe, serviceable, manufacturable hardware that survives heat, dust, vibration, handling, outdoor exposure, lab use, user abuse, and maintenance work.

1. Tool purpose

Protect the user

Keep fingers, tools, wires, liquids, dust, heat, blades, motors, mains terminals, battery terminals, sharp edges, and high-temperature parts away from unsafe contact.

Primary output: hazard-separated physical design.

Protect the electronics

Control airflow, thermal path, vibration, strain relief, ingress, EMI/cable discipline, connector support, service access, and mounting rigidity.

Primary output: enclosure design rules + validation receipts.

Protect the production process

Make the design repeatable through material choice, wall thickness, bosses, fasteners, tolerances, access order, inspection points, and assembly poka-yoke.

Primary output: DFM-ready enclosure release package.
Rule: an enclosure is not decoration. It is a safety boundary, thermal system, service workflow, manufacturing object, and user-interface surface.

3. Production-stage map

Stage A — exposed prototype

Board or mechanism runs on bench, but cables, heatsinks, batteries, motors, and sensors are exposed.

Tool 13 action: define no-touch zones, temporary covers, airflow assumptions, cable strain relief, and safe handling rules.

Stage B — EVT enclosure

First 3D-printed or fabricated enclosure verifies mounting, connector access, heat, clearances, and user handling.

Tool 13 action: run assembly/disassembly, drop/handling, thermal soak, vibration, and connector insertion tests.

Stage C — DVT environmental build

Design starts behaving like a real product under heat, dust, splash, field transport, lab contamination, or workshop abuse.

Tool 13 action: add gaskets, cable glands, vents, filters, guards, labels, material upgrades, and service inspection gates.

Stage D — PVT / supplier release

Manufacturing-ready enclosure package with drawings, tolerances, fastener spec, inspection points, and QA receipts.

Tool 13 action: freeze revision, publish CAD/BOM hash, vendor instructions, assembly order, test fixture, and blocked-use claims.

5. Pass/fail gates

PASS gate

The enclosure can be assembled without forcing, protects unsafe zones, exposes required user/service interfaces, survives expected operating temperature, and has documented inspection evidence.

PASS when:
- No cable is pinched or unsupported.
- No finger/tool can touch dangerous zones during normal use.
- Heat sources remain below material and component limits.
- Service access is possible without destructive disassembly.
- Every CAD/BOM/source file is versioned and hashed.

FAIL gate

The enclosure hides risk, traps heat, blocks service, exposes terminals, lets the user insert parts incorrectly, or lacks manufacturing evidence.

FAIL when:
- Battery/mains/motor/heater terminals are reachable.
- Thermal test is missing or fails at realistic load.
- Sensor, camera, LiDAR, antenna, or optics are blocked.
- Emergency stop or power disconnect is hidden.
- CAD revision cannot be traced to BOM and build photos.

7.2 Environmental DFM decision pattern

IF product_context == outdoor:
    require cable glands + drain/vent path + UV material note + corrosion review
IF product_context == mains_or_battery_high_current:
    require touch-safe cover + fuse access + strain relief + labelled power zone
IF product_context == moving_machine:
    require guard + interlock or guarded access + E-stop visibility + pinch-point review
IF product_context == optics_or_camera:
    require lens/FOV clearance + dust control + calibration target + privacy indicator
IF product_context == lab_or_measurement:
    require calibration fixture + contamination control + claim boundary
